# Pyroduct 模型速查

把两篇中文哲学文本建模为可运行、可测试的 MoonBit 状态机族。每个状态、迁移、
阶段的 `gloss` 载原文措辞；「原文直述」与「模型整理」在每个文件头注明。页码不是
约定——`P.xx` 只在 `multi`／`group`／`society`（及 `evolution` 三处）出现。

## 怎么跑

全部报告经 `moon run cmd/main -- <sub>`（wasm，秒级、零网络、固定种子）：

| 命令 | 输出 |
|---|---|
| `report`（默认） | 主体状态机：34 状态 · 53 迁移 · 11 阶段，定名表、发生论位置 |
| `slots` | 49 个触发 → 8 个驱动槽（处境6·取向6·先行4·行动9·反馈8·持存8·共在3·揭蔽5） |
| `loop` | 位置 × 槽的执行契约：迁／守／未定／无路；272 组合中 228 个无路 |
| `multi` | 两个主体的一次遭遇：体制 × 两诚 × 有效性主张时序 → 判词 |
| `group` / `society` | 群体涌现（20 状态）／双层次社会交往（13 状态） |
| `evolution` | Agent 配置的变异／适应度／宪法／闸门／账本 |
| `cycle` | 主体循环：位置 × 驱动槽 × 因果反馈（修习与开放过同一个闸门） |
| `coordinator` | 科研 Agent 协调器：制品／规划／证据（按置信区间）／决策分段 |
| `dmlref` / `causal` | 外部 DoubleML 互校（θ̂ 差、se 差）／0.75.0 深用诊断：敏感性 rv、BH 校正、BLP 异质性（模型整理） |
| `audit` | 三鉴自审计（模型整理）：主体机当程序读——结构鉴绑定（状态即绑定）／类型鉴契约（无路说出口）／行为鉴轨迹（历程有承载）；4 条已知设计（无忆／无筹只出不进）+ 0 条未预期 |
| `ml` / `ml-export` | 自研 DoubleML 接口与因果实验说明 / 数据集 CSV |
| `mermaid` / `dot` | 状态图源码 |
| `genesis` / `course` / `naming` / `principle` / `intuition` | 主线／环节序列／定名对照表／主体通用性原则／直觉读法（备忘录读成背景直觉的仓库，模型整理） |
| `all` | 报告 + 历程 + Mermaid |

先跑一次 `report` 与 `slots` 再回答模型事实问题；引用具体状态时给出 `naming`
里的一行（定名｜原文名｜原文措辞），要交代出处层则取 `report` 的「派生表与
持久度」一节或 `slots` 的逐槽标注；页码出处只在 `multi`／`group`／`society`
三面印出来，主体机的面没有页码字段。

## 读法纪律

- **未定不是失败**：`step` 返回 未定（多条出路并存）时，机器不替主体决断；
  在 `evolution::run_cycle` 里按双诚之比裁决。回答时别说「卡住」。
- **无路是数据**：228 个无路组合是模型的如实输出（`moon run cmd/main -- loop`
  的缺口表），不是缺页。不编造不存在的迁移。
- **反馈由闸门给出**：`cycle` 演示里缺省主体停在「自身」的持存自环，原因是
  修习与开放两个候选都过不了因果闸门（θ̂=0.012，95% CI 跨零；朴素差 0.467
  是选择偏误）。这是「没有证据就不前进」的正确读法，不是缺陷。
- **出处两层**：状态／迁移／措辞是原文直述；驱动槽八分、循环映射是模型整理。
  引用时注明属于哪层。
- **认出不是重算**：循环报告里「同判·不重裁」是「持存」的取回（背景直觉），
  回溯持平是「揭蔽」的通过——出处见账本的首裁回合；直觉永不宣称终局（不封闭）。
